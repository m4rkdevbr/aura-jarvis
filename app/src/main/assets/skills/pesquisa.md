# Pesquisa com fonte

1. Chame `web_search` com uma pergunta objetiva.
2. Responda em até 3 frases, com o dado principal primeiro.
3. Diga de onde veio ("segundo o site da Anatel...").
4. Se as fontes discordarem ou forem antigas, diga isso. Nunca complete com dado inventado.
5. Ofereça mandar os links pelo Telegram se o usuário quiser ler.
