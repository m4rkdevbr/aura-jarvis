# Resumo para a memória

1. Extraia só o que vale lembrar depois: decisões, pessoas e papéis, prazos, números, preferências.
2. Grave cada item com `remember`, uma frase autossuficiente cada ("Contrato com a Acme vence em 15/12").
3. Pendências com prazo viram tarefas com `add_task`.
4. Fale em 2 frases o que guardou e quantas tarefas criou.
